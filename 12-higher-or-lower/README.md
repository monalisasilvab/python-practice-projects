# Higher or Lower

A terminal-based "Higher or Lower" game that compares follower counts from game_data. Guess which account (A or B) has more followers. Score increments for each correct guess until you miss.

## How to play
- The script prints two formatted accounts (A and B).
- Type A or B to guess which has more followers. Input is case-insensitive.
- If correct, your score increases and the game continues (B becomes the next A).
- If wrong, the game ends and your final score is shown.
